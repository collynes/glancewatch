## Reddit/Community Post Template

---

**Title:** "Show r/selfhosted: GlanceWatch - lightweight Glances + Uptime Kuma adapter"

Hey r/selfhosted!

I built GlanceWatch to solve a simple problem: monitoring my homelab with Uptime Kuma + Glances without wrestling with manual threshold checks.

**What it does:**
- One-command install (`pip install glancewatch`)
- Clean web dashboard + HTTP endpoints
- Returns 200 (healthy) or 503 (unhealthy) based on thresholds
- Works with Uptime Kuma, Healthchecks.io, etc.

**Stats so far:**
- 7,500+ downloads on PyPI
- 3 GitHub stars (growing!)
- Used in personal homelabs → production servers

**I'm here to learn:** What would make this more useful for you?
- Docker container monitoring?
- More granular alerts?
- Different integrations?

Feedback survey (2 min): [link]

## Response Guidelines

**When you get feedback:**

1. **Respond within 24 hours** (even just "Thanks!")
2. **Ask clarifying questions** if vague
3. **Mark feature requests** with labels
4. **Thank every contributor** by name
5. **Share updates** when you implement their ideas

**Example responses:**

**Positive feedback:**
> "Thanks so much! 😊 Really glad it's working well for your setup. If you think of anything that could make it even better, always open to ideas!"

**Negative feedback:**
> "Thanks for the honest feedback — this is exactly what I need to hear. [Specific question about their pain point]. Working on [related improvement] for the next release."

**Feature request:**
> "Great idea! 💡 I can see how that would be useful for [use case]. Adding it to the roadmap. Would [alternative approach] work as a stopgap?"

---

Remember: Every piece of feedback is gold. Even "meh" responses tell you something important. 🎯
